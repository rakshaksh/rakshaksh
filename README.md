## Development Philosophy

I believe good software is more than code that simply works.

I aim to build applications that are:

-   **Practical** --- solving a real problem or serving a clear purpose
-   **Maintainable** --- structured so they can evolve over time
-   **Scalable** --- designed with future growth in mind
-   **User-focused** --- intuitive, responsive, and accessible
-   **Well-engineered** --- with attention to architecture, APIs, data,
    and security

I also believe that becoming a better developer means understanding
**why** something works, not just learning **how** to implement it.
